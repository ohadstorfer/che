# Culture art: Gemini prompts

Two jobs, 10 + 86 images.

## How to use
1. In Gemini (Images, Pro / Nano Banana), start a chat and attach these 4 references once:
   `assets/images/mascot/canva/mate.jpg`, `gaucho.jpg`, `tango.jpg`, `saludando.jpg`.
2. Paste prompts one at a time. Start a new chat (re-attach the 4) about every 15 prompts so the style doesn't drift.
3. Save each image with the **file name shown** as a PNG:
   - Heroes into `assets/images/mascot/culture/heroes/`
   - Objects into `assets/images/mascot/culture/objects/`
4. If Gemini refuses one, reword it slightly and retry; it is usually a false alarm on a flag or an old-fashioned prop.
5. Tell me when a batch is in the folder and I cut them out and wire them into the app.
